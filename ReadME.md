# Feelsync

## Project Overview

Feelsync is a web application where users are able to find music based on a certain mood! After a user selects a mood, various songs similar to that feeling will be displayed and able to be previewed.

Web link: [here](https://feelsync-b6cxghhdhce6e4h6.centralus-01.azurewebsites.net/)

## Technologies Used

**Frontend**
* ReactJS, React Router, Tailwind CSS

**Other**
* Figma for wireframing, Node
