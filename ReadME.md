# Feelsync

## Project Overview

Feelsync is a responsive web application that helps users discover music based on their current mood. Users can select from predefined moods, and the app displays songs that match the emotional tone of the mood. Each song includes details such as title, artist, duration, Spotify link, and a preview option that lets users listen before choosing. Each playlist also has a link to the dedicated playlist.

Web link: [here](https://feelsync-b6cxghhdhce6e4h6.centralus-01.azurewebsites.net/)

## Technologies Used

**Frontend**
* ReactJS + Vite, React Router, Tailwind CSS

**Other**
* Microsoft Azure, Figma, Node
